📚 About StudyNest

StudyNest is a modern student productivity tool designed to help you manage assignments, visualise your weekly timetable and stay focused with daily study goals.

Built as a clean, lightweight web application with no backend or login required. Everything is stored privately in your browser using LocalStorage — your data never leaves your device.

This is version 1.0, designed as both a genuinely useful tool and a portfolio showcase of modern HTML, CSS and JavaScript skills.

Version 1 — Local Storage Only. All data is saved in this browser. Clearing browser data or switching browsers will start fresh. No cloud sync in this version.
